# totalApp
Es un proyecto personal que es una app web de notas, gestionar tus notas y tiene la capacidad tanto de guardar y gestionar notas a nivel local como en servidor en linea para consultar tus notas en cualquier navegador o dispositivo y tenerlas siempre presente.
Esta app web esta hecha en Angular como Front-End y es Serverless, osea que no tiene backend, si no, se apoya en Firebase para guardar los datos.
Para probar la App este es el enlace: https://notetotalapp.netlify.app/dashboard/notes
